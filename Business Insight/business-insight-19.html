1 — Returns Data Structure

The FactReturns table contains return event identifiers, original sales line references, return dates, return reasons, returned quantities, and refund amounts.

Business relevance: The dataset contains the key fields needed to investigate return patterns, product performance, return reasons, and refund amounts.

2 — Overall Returns Overview

  • Total return events: 19,824
  • Distinct return IDs: 19,824
  • Distinct sales lines with returns: 19,824
  • Total returned quantity: 37,665 units
  • Total refund amount: 17,779,981,767.90
  • Return date range: January 2, 2023 – December 31, 2025

Insight: The dataset records 19,824 return events involving 37,665 units, with approximately 17.78 billion monetary units in recorded refunds.

Note: The currency has not yet been identified.

3 — Return-to-Sales Data Integrity

The initial validation identified:

  • Orphan return records: 0
  • Invalid returned quantities: 0
  • Negative refund amounts: 0
  • Individual return rows exceeding the original sold quantity: 0

Insight: No issues were detected in these initial data integrity checks. This supports further analysis, although it does not guarantee that every aspect of the dataset is error-free.

4 — Cumulative Returns Validation

  • Sales lines with returns: 19,824
  • Sales lines where cumulative returned quantity exceeds sold quantity: 0
  • Maximum returned quantity per sales line: 4 units

Insight: No sales line was found to have cumulative returned quantities exceeding its original sold quantity. This provides additional confidence in the consistency of return quantities.

8 — Return Reasons Analysis

Key Findings

  • Wrong Item was the most frequent return reason, with 3,966 return events, accounting for 20.01% of all returns.
  • Defective products also recorded 3,966 return events and accounted for 20.01% of returns.
  • Wrong Size and Not Expected each represented approximately 20% of all return events.
  • Changed Mind had the lowest number of return events, at 3,962 (19.99%).
  • Although return-event counts were almost identical across all five reasons, the total returned quantities and refund amounts varied considerably.

Business Implications

Return reasons are distributed almost evenly by event count, so no single reason dominates return frequency. However, Wrong Item accounts for the highest returned quantity and refund amount, making order accuracy a priority for further investigation. Defective products also represent a significant financial exposure and may warrant a closer review of product quality.

These findings suggest that return-reduction efforts should focus not only on how often returns occur, but also on the quantities and refund amounts associated with each reason.

9 — Return Rate by Sales Channel

Key Findings

  • Online Sales recorded 208,000 units sold and 7,549 returned units, resulting in a unit return rate of 3.63%.
  • In-Store Sales recorded 832,000 units sold and 30,116 returned units, with a return rate of 3.62%.
  • Online sales had a slightly higher return rate, by just 0.01 percentage points.
  • In-store sales accounted for approximately 13.95 billion in refunds, compared with 3.83 billion for online sales. This difference is largely associated with the much higher sales volume in physical stores.

Business Implications

Return rates are nearly identical across both sales channels, suggesting that neither channel clearly stands out as having a higher return problem. The online channel may warrant further investigation, but the 0.01 percentage-point difference is too small to establish a meaningful performance gap on its own.

Future analysis could examine return reasons by channel to determine whether online returns are more strongly associated with sizing, product expectations, or order accuracy.

10 — Products with the Highest Return Rates

Key Findings

  • The top 10 products all recorded a unit return rate of 4.58%.
  • Each product had 1,920 units sold and 88 units returned.
  • The list includes products from both Clothing and Footwear, suggesting that higher return rates are not limited to a single category.
  • Footwear Sandals Model 418 had the highest total refund amount among these products, at approximately 66.52 million.
  • The identical sales and return quantities across all 10 products suggest a consistent pattern in the dataset; further investigation would be needed to determine whether this reflects actual product behavior or synthetic data generation.

Business Implications

These products are candidates for further investigation, but the identical return rates mean they cannot be meaningfully ranked against one another based on return rate alone. Reviewing return reasons for these products could help identify whether sizing, product defects, incorrect fulfillment, or unmet customer expectations are contributing to returns.

The results should be treated as investigation priorities rather than proof that these products have quality problems.
